# 학습 모듈별 UI 이질성에 대한 냉정 분석 보고서

현재 가나(`Kana`), 단어(`Vocab`), 문법(`Grammar`) 학습 모듈이 서로 다른 UI 구조를 가지고 있는 현상에 대해, 학습 효율과 디자인 시스템 관점에서 냉정하게 비판하고 개선 방향을 제안합니다.

## 1. 냉정한 현상 진단: "하나의 앱, 세 개의 철학"

### A. 가나 학습 (Grid & Modal) - **[가장 세련됨]**
- **특징**: 격자형 차트에서 항목을 선택하면 컴팩트한 모달이 뜨는 방식.
- **피드백**: 가장 완성도가 높고 우리 앱의 'Zen UI' 컨셉을 잘 보여줍니다. 모달 내의 상호작용이 밀도가 높고 직관적입니다.

### B. 단어 학습 (Flashcard & Swipe) - **[과도기적 상태]**
- **특징**: 화면 전체를 카드가 차지하고 스와이프로 넘기는 방식. 가나 학습의 '모달' 방식과는 공간감이 완전히 다릅니다.
- **피드백**: 가나 학습은 '팝업'인데 단어 학습은 '전체 화면'인 점은 사용자에게 맥락 전환(Context Switch)의 피로를 줍니다. 또한, 단어 학습에서의 스와이프와 가나 학습의 버튼 조작 방식이 서로 충돌하고 있습니다.

### C. 문법 학습 (Catalog & Presentation) - **[가장 이질적임]**
- **특징**: 리스트 형태의 카탈로그에서 상세 페이지로 들어가는 방식.
- **피드백**: **"앱 내에 다른 앱이 있는 느낌"**입니다. 애니메이션 효과만 비슷할 뿐, 학습 인터페이스 자체는 일반적인 교육 앱의 전형을 따르고 있어 우리 앱만의 필기 기능이나 스와이프 제스처가 전혀 녹아있지 않습니다.

---

## 2. UI 불일치가 학습에 끼치는 악영향
1.  **조작 습관의 파편화**: 가나 학습에서 익힌 '필기 모드 진입' 방식이 단어 학습에서는 다르게 작동하거나, 문법에서는 아예 존재하지 않아 유저의 학습 리듬을 깹니다.
2.  **데이터 해석의 혼란**: FSRS 등급을 매기는 방식이 모듈마다 제각각이면, 사용자는 자신의 실력을 직관적으로 파악하기 어려워집니다.
3.  **브랜드 가치 하락**: 프리미엄 앱은 '하나의 통일된 질감'을 유지해야 합니다. 현재는 기능마다 개발자가 다른 듯한 인상을 줄 수 있습니다.

---

## 3. 로드맵: "Universal Learning Interface"로의 통합

### [개선 안 1] 'Handwriting Modal'을 표준 인터페이스로 채택
- 가나 학습에서 검증된 **'컴팩트 모달'** 방식을 단어 학습에도 적용해야 합니다.
- 전체 화면 카드 대신, 대시보드에서 단어를 선택하면 가나 연습처럼 모달이 떠서 빠르게 훑고 닫는 방식으로 통일하여 공간적 일관성을 확보합니다.

### [개선 안 2] 제스처 평가 시스템의 표준화
- 모든 학습 모듈(문법 포함) 하단에 **동일한 스와이프 핸들**을 배치합니다.
- 문법 예문을 읽든, 단어를 외우든, 가나를 쓰든 **"오른쪽으로 밀면 쉬움, 왼쪽은 다시"**라는 공통의 물리적 언어를 심어야 합니다.

### [개선 안 3] 문법 학습의 '액티브 카드'화
- 현재의 긴 문법 설명 페이지를 단어 학습과 같은 **'카드 레이아웃'**으로 분절화해야 합니다.
- 문법 패턴 하나하나를 하나의 카드로 취급하여, 가나/단어와 동일한 인터페이스 내에서 학습할 수 있도록 구조적 통합이 필요합니다.

---
**최종 결론**: 현재의 UI 이질성은 **"반드시 개선해야 할 심각한 마찰 요소"**입니다. 각 모듈의 특수성(가나의 단순함 vs 문법의 복잡함)은 인정하되, 사용자가 도구를 다루는 **'상호작용의 문법(UI Grammar)'**은 반드시 하나로 통합되어야 합니다.

> [!IMPORTANT]
> **냉정한 한 줄 평**: "아름다운 부품들이 모여 있지만, 아직 하나의 기계로 조립되지는 않은 상태"입니다. 'Handwriting Modal'과 'Integrated Gesture'를 중심으로 전체 UI를 재조립해야 합니다.
