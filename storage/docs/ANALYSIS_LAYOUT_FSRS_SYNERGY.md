# Zen UI 레이아웃과 FSRS 시스템 간의 케미스트리 연구 보고서

우리 앱의 디자인 철학인 **'Zen UI'**와 차세대 간격 반복 알고리즘인 **'FSRS'**가 결합되었을 때 창출되는 시너지와 프리미엄 유저 경험에 대한 연구 결과입니다.

## 1. 정적인 레이아웃에서 '살아있는 데이터'로의 진화
현재의 레이아웃은 아름답지만 고정된 상태입니다. FSRS가 도입되면 UI는 사용자의 망각 속도에 반응하는 **'살층(Living Layer)'**으로 변모합니다.

- **데이터 기반 아우라 (Stability Visualization)**: 
    - FSRS의 `Stability`(안정성) 수치에 따라 필기 카드의 배경색, 보더의 빛나는 정도, 혹은 질감을 미세하게 조절할 수 있습니다. 
    - 예: 안정성이 낮은(곧 잊힐) 카드는 미세하게 흔들리거나 그림자가 얕아져 '위태로움'을 암시하고, 완전히 내재화된 카드는 '견고하고 맑은' 유리스모피즘 효과를 적용.

## 2. 인터랙티브 피드백: '4단계 버튼' vs 'Zen Minimal'
FSRS는 4단계(Again, Hard, Good, Easy) 피드백을 요구합니다. 이를 현재의 컴팩트 레이아웃에 녹여낼 최적의 방안은 다음과 같습니다.

- **Floating Action Feedback (Grounded Implementation)**:
    - 현재 하단의 **[volume, casino, undo, delete, visibility]** 버튼 그룹 위에 FSRS용 4단계 버튼을 나란히 배치하기보다, **[visibility]** 버튼 옆에 `Result` 버튼이 활성화되거나, 필기 완료 시 컨트롤 바의 레이아웃이 4단계 등급(Again, Hard, Good, Easy)으로 부드럽게 전환(Transition)되는 형태가 적합합니다. 
    - **케미스트리**: 현재 구현된 `framer-motion` 애니메이션을 활용하여, 필기가 멈춘 상태에서만 평가 버튼이 나타나게 함으로써 학습 흐름을 방해하지 않는 Zen UX를 유지합니다.

- **제스처 기반 평가 (Gesture Integration)**:
    - 현재 **하단 리얼타임 스와이프 핸들**은 '카드 넘기기' 전용입니다. 이를 확장하여 왼쪽으로 스와이프하면 `Hard`, 오른쪽은 `Easy`와 같이 현재의 스와이프 로직에 직접 FSRS 평가를 매핑할 수 있습니다.
    - **케미스트리**: 유저는 별도의 버튼 클릭 없이, 현재 구현된 "손맛"이 살아있는 스와이프 동작만으로 다음 문제로 넘어가면서 동시에 학습 결과까지 저장하게 됩니다.

## 3. 적응형 스캐폴딩 (Adaptive Scaffolding - Implementation Note)
- **난이도 비례 가이드**: 
    - 현재 구현된 `showGuide` 상태와 FSRS의 `Stability` 데이터를 연동합니다. 
    - 안정성이 아주 낮은(처음 배움) 항목은 `showGuide`가 강제로 켜지거나 가이드 선명도가 100%로 시작하고, 복습 주기가 길어질수록 가이드의 초기 투명도가 `0.3`, `0.1` 식으로 점차 낮아지게 설계합니다.
    - **케미스트리**: 유저는 "가이드 버튼"을 수동으로 누를 필요가 점점 줄어들며, 알고리즘이 자신의 성장을 뒷받침해주는 프리미엄한 감각을 경험합니다.

## 4. Mastery Board와의 결정적 시너지 (The Knowledge Map)
- **동적 군집화 (Dynamic Clustering)**:
    - Mastery Board에서 글자들이 단순 나열되는 것이 아니라, `Retrievability`(재현율)가 낮은 것들이 중앙으로 모여들거나 '붉게' 활성화됩니다.
    - 유저는 "오늘 뭘 공부하지?"라고 고민할 필요 없이, 가장 밝게 빛나거나 중앙에 모인 글자들을 터치하는 것만으로 최적의 학습 세션에 진입합니다.

---

## 5. 결론: "차갑지 않은 기술, 따뜻한 인텔리전스"
단순한 알고리즘(FSRS)은 차가운 수학입니다. 하지만 이를 우리의 Zen UI와 결합하면 **"내가 공부하는 것이 아니라, 앱이 나를 학습시켜준다"**는 프리미엄한 개인 비서의 경험으로 승화됩니다.

> [!IMPORTANT]
> **핵심 가치**: 유저는 FSRS라는 복잡한 이름을 알 필요가 없습니다. 그저 "이 앱은 이상하게 내 마음(기억)을 잘 읽네?"라는 감탄만 남기면 됩니다. 이것이 우리가 추구할 진정한 **Zen UX Chemistry**입니다.
